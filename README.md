# Сводка по городу

CLI-утилита получает координаты и текущую погоду из Open-Meteo,
курс валюты к рублю — из Frankfurter. API-ключи не требуются.

## Установка

Нужен Python 3.9+.

```bash
python -m venv .venv
python -m pip install -r requirements.txt
```

## Запуск

Команды выполняются из каталога `city_summary`:

```bash
python main.py --city Moscow
python main.py --city Moscow --currency EUR
python main.py --city Moscow --json
```

При одинаковых названиях населённых пунктов используется первый
результат геокодинга. Для уточнения можно передать город с названием
страны, например `--city "Paris, France"`.

## Правила

- Если температура ниже 0°C, `warm_clothes` равно `true`.
- Если курс строго выше 100 RUB, `expensive` равно `true`.

## Коды выхода

- `0` — сводка получена;
- `2` — ошибка аргументов CLI;
- `3` — город или валюта не найдены;
- `4` — внешний сервис недоступен либо вернул некорректный ответ.

Каждый GET-запрос имеет timeout 5 секунд и максимум три попытки.
При HTTP 429 числовой заголовок `Retry-After` определяет паузу
перед повтором. Данные курса берутся из внешнего API при каждом
запуске; кэш не используется.
